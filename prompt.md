# `prompt.md`

Это можно положить в корень проекта, чтобы выполнить требование тестового.

```md
Prompt

Сгенерируй Java Spring Boot приложение для тестового задания.

Нужно реализовать минимальное чат-приложение по типу ICQ.

Требования:

1. Java 21.
2. Spring Boot.
3. REST API.
4. База данных H2 через Spring Data JPA.
5. Пользователи должны храниться в БД.
6. Сообщения должны храниться в БД.
7. Пользователь может отправить сообщение другому пользователю.
8. У сообщения должны быть статусы:
   - SENT
   - DELIVERED
   - READ
9. Сервер должен поддерживать асинхронную доставку событий через Server-Sent Events.
10. Каждый пользователь должен подписываться на свой SSE stream и получать только свои события.
11. Добавить endpoint для получения истории переписки двух пользователей.
12. Добавить endpoint для отметки сообщения прочитанным.
13. Добавить валидацию входящих запросов.
14. Добавить централизованную обработку ошибок через RestControllerAdvice.
15. Добавить README.md с инструкцией запуска.
16. Добавить Dockerfile и docker-compose.yml.

Нужна простая, но чистая структура проекта:

- controller
- service
- repository
- model.entity
- model.dto
- model.enums
- exception

Использовать Lombok аккуратно: @RequiredArgsConstructor в сервисах и контроллерах, @Getter и защищённый no-args constructor в JPA entity. Не использовать @Data на JPA entity.
Код должен быть полным и запускаемым.
